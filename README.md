# 🔵🔴 FC Barcelona Squad & Roster App
Веб-сайт для просмотра статистики, поиска, просмотров хайлайтов игроков Барселоны на сезон 2026/2027 

## Функционал

**Живой поиск:** Мгновенная фильтрация игроков по имени или номеру прямо во время ввода.

**Интерактивное модальное окно:** При клике на карточку игрока открывается окно с его детальной статистикой и встроенным YouTube-плеером хайлайтов.

**Адаптивный UI:** Плавные hover-анимации, двухколоночная верстка модального окна и фирменное оформление в цветах клуба.

**Контроль медиа:** Автоматическая остановка воспроизведения видео при закрытии модалки.
